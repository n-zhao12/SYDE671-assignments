Part Two · Images of the Russian Empire

Three exposures. One color photograph.

Sergei Prokudin-Gorskii recorded scenes on glass plates through red, green, and blue filters. This project separates the stacked exposures, aligns them, and combines them into color images.

See the resultsView source code

The problem

Each grayscale scan contains three exposures stacked vertically in blue, green, red order. Small shifts between exposures produce colored fringes unless the channels are aligned before combination.

01 · Split

Extract channels

Divide each plate into three equal-height sections: blue is the reference, and green and red are the moving channels.

02 · Align

Search translations

Estimate an (dx, dy) shift for green and red relative to blue. Compare valid overlapping interior pixels, not wrapped pixels.

03 · Reconstruct

Combine and improve

Apply shifts, crop to the shared valid region, combine channels, then rescale contrast for display.

Alignment methods

The implementation includes exhaustive single-scale search and a coarse-to-fine image pyramid.

Single-scale baseline

For each candidate translation, compare the reference and shifted channel. Raw NCC mean-centers the regions and scores their normalized dot product; L2 is the Euclidean pixel difference. NCC is maximized; L2 is minimized.

Single-scale NCC outputs available for two low-resolution images

Coarse-to-fine pyramid

Repeatedly downsample by two, find a coarse translation, scale it back up, and refine locally at each finer resolution. This makes a wider effective search practical for large scans.

The reported vector is the shift applied to the moving channel.

Texture-weighted NCC

An extension weights pixels by Sobel gradient magnitude in the blue reference, giving detailed regions more influence than smooth areas. Basic NCC results are included separately.

Bells & whistles

Implemented: Automatic contrast rescales each final image so its overall minimum becomes 0 and maximum becomes 255. For alignment, gradient NCC compares Sobel gradient magnitudes; texture-weighted NCC uses the blue reference's Sobel magnitude to give detailed pixels greater weight while comparing the original intensity values. These are optional alignment metrics; the three selected examples above use texture-weighted NCC.

Crop limitation: After alignment, the program crops to the region shared by all shifted channels so no wrapped pixels remain. The 5% edge exclusion is applied only when scoring candidate shifts. This does not detect and remove the original plate's dark or light frame, as described in the assignment's automatic-cropping suggestion. White balance and a separate color-channel mapping are not implemented.

What worked—and what remains

Strengths

The pyramid narrows full-resolution search to local refinements. Overlap-aware scoring and edge exclusion reduce false matches from rolled pixels and plate borders. Texture weighting emphasizes detailed regions.

Limitations and next steps

Translation-only alignment cannot correct rotation, scale changes, or local warping. Some color fringing remains around strong edges and plate borders. The provided-image pyramid NCC offsets are listed above. The low-resolution single-scale NCC/L2 comparison and pyramid L2 results remain to be added if not already completed.
