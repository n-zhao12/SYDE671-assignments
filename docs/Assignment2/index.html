Main takeaway

Filters shape which image details matter.

The most important thing I learned is that choosing a filter means choosing which spatial details to keep or emphasize. Gaussian smoothing suppresses fine texture, derivatives reveal intensity changes, and sharpening adds high-frequency detail back. Hybrid images and multiresolution blending extend the same idea by assigning different roles to different frequency scales. The filter scale should match the structures I want the viewer to notice.
